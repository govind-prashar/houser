# Light & Premium Design System Style Guide

## 1. Color Palette

### Primary Backgrounds
- **Background**: `#F9FAFB` (Soft Off-White) - Main page background.
- **Card Surface**: `#FFFFFF` (Pure White) - Cards, modals, dropdowns.

### Text Colors
- **Primary Text**: `#0F172A` (Deep Slate) - Headings, main copy.
- **Secondary Text**: `#475569` (Slate 600) - Supporting text.
- **Muted Text**: `#94A3B8` (Slate 400) - Meta data, placeholders.

### Accents
- **Primary Accent**: `#2563EB` (Luxury Blue) - CTAs, active states, links.
- **Secondary Accent**: `#0D9488` (Teal Freshness) - Success states, badges.
- **Warm Highlight**: `#F59E0B` (Sunset Gold) - Use sparingly for ratings/badges.

### Borders
- **Border**: `#E5E7EB` (Gray 200) - Subtle separation.

## 2. Typography

**Font Family**: `Inter`, system-ui, sans-serif.

| Role | Size (Desktop) | Size (Mobile) | Weight | Line Height |
|------|---------------|---------------|--------|-------------|
| H1   | 56px          | 36px          | Bold   | 1.1         |
| H2   | 36px          | 28px          | SemiBold| 1.2         |
| H3   | 24px          | 20px          | Medium | 1.3         |
| Body | 16px          | 16px          | Regular| 1.6         |
| Small| 14px          | 14px          | Regular| 1.5         |

## 3. Shadows & Radius

- **Card Shadow**: `0 10px 30px rgba(15, 23, 42, 0.08)`
- **Hover Shadow**: `0 20px 40px rgba(15, 23, 42, 0.12)`
- **Border Radius**: `16px` (Cards), `9999px` (Buttons)

## 4. Animation

**Curve**: `cubic-bezier(0.22, 1, 0.36, 1)` (Smooth, springy but restrained).
**Duration**: `200ms` - `300ms` for hover/interactions.

## 5. Components

### Buttons
- **Primary**: Solid Blue (`#2563EB`), White Text.
- **Secondary**: Ghost/Outline, Slate Text.

### Cards
- White background.
- 1px Solid `#E5E7EB` border.
- Gentle hover lift (`-6px`).
